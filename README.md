# Therapify

MERN mental wellness application.

- backend/: Express API for authentication, journals, moods, chat, wellness, recommendations, and Events.
- frontend/: React frontend.
- shared/: shared utilities and wellness catalog.
- MongoDB Atlas: existing application database for all modules.

Run npm start in backend/ and npm run dev in frontend/. Keep the existing backend environment and set frontend VITE_API_URL to the main backend URL. See [Events setup and verification](backend/EVENTS.md) for free event registration.
